    Questions, answered.

    Does it cost anything?

    No. There’s no account and no payment. Open the builder and use it.

    Where does the README go?

    GitHub shows a profile README from a public repository whose name matches your username, for example fullan/fullan. Put README.md at its root.

    Do I need to log in or give a token?

    No. Profilewright only reads public GitHub data. A server owner can set GITHUB_TOKEN to raise GitHub’s rate limit, but visitors never need one.

    Will the cards update when I commit?

    Yes. Cards are images served by Profilewright, so they redraw from your latest public data. Responses are cached for an hour.

    Why don’t the cards load on github.com?

    Card URLs point at the server that made them. When you self-host, set PUBLIC_URL to your deployed address so GitHub can reach the images.

    Can I change it later?

    Yes. The output is plain markdown, and the builder keeps your whole arrangement in its link, so you can reopen it and keep editing.
